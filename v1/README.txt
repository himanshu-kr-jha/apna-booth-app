Apna Booth app v1 - prototype screens (HTML)

Open index.html in Chrome (double-click works; no server needed).

Screens: Main (Home), RollWatch, Queue (Poll Day), Report, Ward, Safety, Access (accessibility hub with pick-up/drop,
Booth Buddy, companion voter, home voting, ISL), Rehearsal (EVM ballot), RampCheck, Simple (simple mode), Chat (Sahayak),
AiVoice (Listen & Translate incl. ISL and Braille), CeoConsole (CEO Office voter-roll de-duplication, desktop layout).
support.js is the prototype runtime (bundles React). All data is dummy.
